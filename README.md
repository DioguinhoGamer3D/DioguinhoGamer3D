# Olá, eu sou o Diogo 👋

Desenvolvedor focado em **back-end com Java e Spring Boot**, e também construindo interfaces com **React e TypeScript**. Gosto de projetos que resolvem problemas reais do dia a dia, como o controle das minhas próprias finanças.

## 🚀 Projeto em destaque

### [💸 DinDin](https://github.com/DioguinhoGamer3D/DinDin)
Sistema de controle de gastos e finanças pessoais (web app / PWA).

- API REST com **autenticação JWT**, CRUD de categorias e transações
- Banco **PostgreSQL** com migrations **Flyway**
- Testes de repositório com **Testcontainers**
- Frontend em **React + TypeScript + Tailwind** (em desenvolvimento)
